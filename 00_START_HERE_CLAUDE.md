# SPOT-ARB — независимый аудит производительности Rust / R1410J
Дата среза: 25 ноября 2026. Аудитор Claude не имеет доступа к серверу. Работай только с приложенным архивом. Не подтверждай тесты, которые не выполнял. Это запрос на независимое исследование, не на запуск торговли и не на автоматическое внесение исправлений.

## Цель
Объяснить, почему система RAM-first на реальных публичных котировках не выдерживает текущий динамический набор инструментов и аварийно останавливается на 50-мс watchdog UCM. Выявить избыточную работу, разделить доказанное и гипотезы, предложить минимальный проверяемый путь исправления без разрастания архитектуры.

## Неприкосновенный контракт
Market data → валидация → состояние рынка в RAM → сравнение → Decision → Risk/Safety → допущенный TRADE_INTENT durable до первого ордера → полная история исполнения. Отрицательные сигналы, обычные котировки и предторговые отказы не должны инициировать записи торговых БД. После допуска сохраняются все результаты, включая неуспешные сделки. 800 мс свежесть, независимый dual-HOT, generation/sequence, FIFO lifecycle, fail-closed. REAL OFF, kill ENGAGED, PAPER NO-GO. Production, DB1, DB2, UNIVERSUM не изменять. Не предлагать увеличивать очереди, 50-мс watchdog, порог свежести или квоты для сокрытия дефекта. Не заменять текущий сканер фиксированным списком 40/235. Сканер на момент тестов обнаружил 234; число динамическое. Все будущие нагрузочные проверки на реальных публичных котировках; архивные и синтетические данные не доказывают производительность.
